# gusbb

A simple static website for Gus BB built with Tailwind CSS.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Build the CSS:
```bash
npm run build
```

## Development

To start development with auto-rebuilding CSS:
```bash
npm run dev
```

Then open `index.html` in your browser.

## Deployment

The site is a static website that can be deployed to any static hosting service. The built files include:
- `index.html` - Main HTML file
- `styles/output.css` - Compiled Tailwind CSS

Simply upload these files to your web server or hosting service (GitHub Pages, Netlify, Vercel, etc.).

## Features

- ✅ Tailwind CSS for styling
- ✅ SEO meta tags
- ✅ Open Graph tags for social sharing
- ✅ Twitter card meta tags
- ✅ Mobile responsive
- ✅ Modern HTML5 structure
